# Hotel Booking Application

A modern Blazor Web App for browsing and booking hotel rooms, built with .NET 8 and Blazor components.

## Overview

This application demonstrates a complete hotel reservation workflow using Blazor Server and UI components. Users can browse hotels, filter by various criteria, view room details, check availability on a map, and complete bookings with print support.

## Features

- **Hotel Browsing** - Browse available hotels with detailed room information including amenities, pricing, ratings, and reviews
- **Smart Filtering** - Filter by check-in/out dates, price range, hotel amenities, and room amenities
- **Sorting Options** - Sort by top rating, price (low to high), or price (high to low)
- **Room Availability** - Real-time availability checking based on booked dates
- **Interactive Maps** - View hotel locations on an interactive map
- **Booking System** - Complete booking flow with personal information form, validation, and confirmation
- **Print Support** - Print booking receipts directly from the confirmation dialog
- **Responsive Design** - Optimized for desktop and mobile devices

## Prerequisites

- [.NET SDK 8.0](https://dotnet.microsoft.com/download/dotnet/8.0) or later
- [Visual Studio 2022](https://visualstudio.microsoft.com/vs/) or later
- [Visual Studio Code](https://code.visualstudio.com/)

## Getting Started

### Clone the repository

```bash
git clone https://github.com/SyncfusionExamples/blazor-grid-hotel-reservation-application.git
cd blazor-grid-hotel-reservation-application
```

### Run with Visual Studio

1. Open the solution file using Visual Studio 2022 or later.
2. Restore the NuGet packages by rebuilding the solution.
3. Build the project to ensure there are no compilation errors.
4. Run the project.

### Run with .NET CLI

```bash
# Restore dependencies
dotnet restore

# Run the project
dotnet run
```
